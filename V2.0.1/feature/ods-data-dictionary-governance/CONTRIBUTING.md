# OGDIL 贡献指南

感谢你对**在线游戏决策智能实验室（Online Gaming Decision Intelligence Lab）**的关注与贡献意愿。

## 如何贡献

1. Fork 本仓库
2. 创建功能分支（`feature/你的功能名称`）
3. 遵循开发规范
4. 在适用的情况下编写测试
5. 向 `develop` 分支提交 Pull Request

## 行为准则

- 保持尊重与建设性
- 优先保证可复现性与科学严谨性
- 清晰地记录你的工作

## 开发环境设置

参见 `docs/01_Project/Development_Standards.md` 与 `ROADMAP.md`。

## 提问

请开一个带有 `question` 标签的 Issue。
