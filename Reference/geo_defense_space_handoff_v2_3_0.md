# 地緣戰略、國防工業與宇航生態資料工程交接書 v2.3.0

日期：2026-10-08。交接標識：`GDS-249-20261008-v2.3.0`。本文件從本對話與現有本地附件提煉，未將未經驗證敘述升格為事實。

## 壹、用戶當前指令／凍結範圍
1. 全球指**地球地理空間**；使用 ISO 3166-1 作 249 國家／地區的現代地理母表，不等同 249 主權國家；歷史及海空天資料需要額外空間標識。
2. **暫停聯合國 SDG DataContacts 與季度封存表的業務分析**，因欄位業務定義、缺值與 schema 對照尚未符合用戶驗收。並非宣稱所有聯合國資料無價值。這不阻止使用 UNOOSA 的公開太空物件登記或其他明確語意的官方資料。
3. 研究優先序調整為**地緣戰略／國防工業的公開經濟與供應鏈資料／商業宇航／衛星地球觀測／氣象及災害韌性**。禁止將國防經濟研究轉為武器目標選擇、攻擊優化、即時軍事追蹤。
4. 不連接 Superset、StarRocks、DolphinScheduler、任何博彩網站及公司的舊伺服器；只使用授權公開資料、離線檔案與合成測試。私人、機密資料不得繞過控制取得。

## 貳、對話沿革／已有資產
- 初始由 weather.com 商業 API、氣象平台訂戶、競爭服務、地緣情報、軍工與宇航生態供應商展開。
- v1.0–v1.1 建立 ISO 3166-1 249 個地區與 31 個氣象等服務供應商的參照表；249×31=7,719 為**待逐國證實矩陣**，不是實測覆蓋率。
- v1.2–v1.6 擴展全球法人／組織／來源／授權目錄；v1.7–v1.8 增建 85 研究領域與歷史時態 SQLite；v1.9–v2.1 建立離線匯入器。
- 2026-10-08 真正取得三件 GLEIF Golden Copy、ISIC Rev.5 結構與解釋附件；獨立審計庫已有 830 條 ISIC 分類、GLEIF 三種來源各 2,000 筆樣本（非全球全量）；SDG ZIP 前綴樣本檢查後，**本輪不再繼續 SDG 分析**。
- `Aerospace_Ecosystem_Report.qmd` 是較早工程研究稿，提及 NASA VEDA、Palantir、時序資料庫、軍用資料平台等；其中軟體企業是否真有部署、合同數字、ITAR/CMMC 白名單限制等**未逐句完成外部獨立核證，不能直接當作確立事實**。
- 附件快照及本輪 SHA-256 見 `geo_defense_space_handoff_v2_3_0_baseline_sha256.csv`；指紋證實本地檔案位元組身份，**不等同官方發行者簽署或內容真偽認證**。

## 肆、可落地之非作戰商業原型（未證實已獲利）
**P1 衛星影像＋公開設施名錄：能源／港口／房地產長期風險。** 先建立合法 Sentinel 影像、GEM 能源設施、NOAA 歷史極端天氣多時間版本關聯；對 50 個隨機且已知的設施核對座標、變更事件及來源；用遮蔽歷史時間段做回測。衡量定位誤差、變化檢出率、人工複核時間、資料成本、客戶驗收。

**P2 宇航合規與航天生態目錄。** 使用 UNOOSA 正式／非正式來源標記、全球法人 LEI 和公開衛星產品資料，提供發射登記文書核對與市場研究；不把 LEI 關係誤認衛星持有權。驗收：100 個太空物件記錄的登記文件鏈接核對率與歷史修訂可追溯率。

**P3 國防工業公開宏觀經濟研究。** SIPRI 年度軍費與貿易資料、ISIC 活動代碼及合法公司公開年報做宏觀市場研究，不輸出武器目標與軍事行動建議。驗收：來源重現率、國別時點對齊、TIV 與財務口徑隔離、授權及付費客戶測試。

**P4 氣象／宇航資料服務比較與災害韌性。** 使用 NASA／NOAA／Copernicus 開放資料作可核驗基線，將 Weather Company、Tomorrow.io、Spire 等作供應商候選；不得以宣稱全球覆蓋代替逐區可用性。驗收：持出地區與年份的預報誤差、事件召回率、時效、每萬次查詢成本、當地授權。

## 伍、七策
- **redteam**：檢查來源偽造、GIS 假座標、衛星時間戳與雲層遮蔽、授權違規、衝突事件與國防資料的敏感性、變更檔污染。
- **critic**：目前只是來源已查證與本地目錄保留，**本輪並未實測任何 249×來源的全域 API 覆蓋，更未證實商業收入**。
- **killcritic**：將每一產品的價值拆為官方金標、誤差、成本、版本、簽訂付費及可重現報告，不達標即淘汰。
- **blindspot**：國界並不足以覆蓋海洋、公海、南極、近地軌道；歷史地名／地緣爭端須中立時態地理層；SIPRI 並非逐合同成交額。
- **blueprint**：地理與歷史時態層 → 授權來源目錄 → 不可變原始檔 SHA-256 → ETL/Parquet → 地理空間索引 → 實體與產業知識圖 → 可重播回測 → 市場驗證。
- **cheatsheet**：`CATALOGUED≠INGESTED≠VERIFIED≠MONETIZED`；`SHA256≠官方數位簽章`；`ISO249≠249主權國`；`SIPRI_TIV≠美元成交額`；`軍費≠軍力`；`已公開≠可自由商業轉售`。
- **actionplan**：保留 249 母表及宇航報告→重建來源授權核對表→下載一個合法、明確 schema 的地球觀測／設施資料集→小型可重現分析→外部金標比對→成本／付費試驗→具證據後擴展全球。
