# 寰宇輿圖 · Windows 11 + WSL2 可互動地球技術示範

## 本版本已提供

- 在登入 Windows 11 後，以瀏覽器啟動 MapLibre GL JS 三維地球；切換三維球面／二維平面、旋轉、縮放及城池定位。
- 導覽至 OpenSpace（完整宇宙視覺化）及 NASA Solar System Treks（月球、火星等）。**星際導航目前是開啟獨立產品，不是同一地圖引擎無縫縮放。**
- 歷史時代下拉選單只是介面佔位；尚未載入可靠的歷史地理資料。
- 城池示範不包含真人、族群數據、軍事情報、人口能力分數或虛構的真實指標。

## 執行（無須改動系統）

Windows PowerShell 先檢查：

```powershell
wsl --status
wsl --list --verbose
```

若已安裝 Ubuntu WSL2：

```bash
cd /mnt/c/Users/<你的Windows帳戶>/Downloads/huaxia_cosmos_mvp
python3 -m http.server 8000 --bind 127.0.0.1
```

**請將路徑修改為本機實際解壓縮位置**。在 Windows 瀏覽器打開：

`http://localhost:8000/`

或直接在 Windows PowerShell 使用（電腦已具 Python 才可）：

```powershell
cd "$env:USERPROFILE\Downloads\huaxia_cosmos_mvp"
py -m http.server 8000 --bind 127.0.0.1
```

使用者自行啟動 HTTP 服務後，在瀏覽器開啟同一網址即可。

## 登入前：Windows 11

**設定 → 個人化 → 鎖定畫面 → 背景選「圖片」／「投影片放映」 → 選 NASA 地球照片 → 開啟「在登入畫面顯示鎖定畫面背景圖片」。**

注意：登入畫面通常只能使用系統允許的背景與資訊，不能當作一般瀏覽器跑即時 Google 地圖。**本示範不修改 Windows 認證介面。**

## 登入前：原生 KDE Plasma Linux（若日後改用）

**系統設定 → 色彩與主題 → 登入畫面（SDDM） → 選擇登入主題 → 更改背景。** 版本的選單文字可能不同；不要為了顯示實時地圖，把 API 密鑰、外網瀏覽器或複雜腳本放進高權限登入管理器。

## 地圖版權與生產部署

- MapLibre GL JS 是開源引擎；本頁引用其官方示例用 `https://demotiles.maplibre.org/style.json`。示例圖磚不承諾正式產品穩定性、使用配額及服務等級；商用前換成有明確商用授權的服務或自建地圖瓦片。
- Google Maps 3D 可以透過付費官方 API 導入，但 Google Maps／Earth 的內容不可未經授權抓取、離線儲存或重售為自主地圖資料。
- OpenHistoricalMap 的資料多數可公開再用，但部分元素可能有特殊授權，且歷史史實須獨立核驗。
- NASA 圖片一般可依其媒體使用規範重用，須標註來源並不得暗示 NASA 背書。

## 下一步研究架構

`Windows／Plasma 前置視覺 → MapLibre（地球） → PostGIS（地理） → OpenHistoricalMap（史地時間） → 人物資料治理（虛構角色／同意真人／群體統計） → OpenSpace（星際） → 決策規則與審計`。

市場前不要直接模仿《三國志》等遊戲專有素材、商標與獨特視覺元素；以歷史事實與自創遊戲機制重新研發。
