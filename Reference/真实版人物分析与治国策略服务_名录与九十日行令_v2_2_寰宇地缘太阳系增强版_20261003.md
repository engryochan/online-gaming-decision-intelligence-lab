### v2.2 寰宇地缘与太阳系强化回执（2026-10-03 第四次复核）

本版以 v2.1 为不可破坏基线：**原 37 戏、六族、十二门、#1–#85、百业 A–V、十五类人物卡、redteam／critic／killcritic／blindspot、四层架构、三横梁、九家分职、七联单、原十三事、G0–G3 与附录 A/B 全部保留**；只增加地球—轨道—地月—月球—火星—太阳系六级地缘母架构，以及公开、非操作性的地缘军事／军工产业链、地缘经济、地缘民生、地缘 AI、地缘宇航、地缘生态与空间治理资料。

本版新立五条边界：

1. **古典为体，现代为证**：以《管子》《孙子》《墨子》《战国策》《吕氏春秋》《史记·货殖列传》等作问题框架与中文命名；天体位置、轨道、法律、经济、气候、人口等事实仍以现代天文学、统计学、法学、遥感、经济学和一手资料为准。
2. **全球不等于国家排行榜**：地缘研究对象扩为 `人—家庭—企业—产业—地区—国家—网络—基础设施—自然系统—轨道—天体`，不得把单一“综合国力值”当作世界真相。
3. **太空不等于领土延伸**：外空、月球与其他天体适用不同法律制度；不得把地面主权地图直接外推成“月球国界”或“火星领土”。
4. **计划不等于实绩**：所有空间项目强制标记 `operational / under_development / announced / conceptual / retired`；公开路线图、采购、合作倡议与已经投入运营的基础设施分栏。
5. **军工只作公开宏观与韧性研究**：允许研究公开军费、军工产业、供应链、空间安全、冲突风险与民生外溢；不提供目标选择、打击优化、武器效能参数组合、薄弱点利用或现实作战行动教范。

> **v2.2 母句**：地有经纬，天有轨道；地上以民生为本，天上以科学与可持续为界。凡地缘之数，先问尺度、时点、坐标、法域与证据，再问趋势与策略。

## 政商民百业生态总纲：以 MSIC 2025／ISIC Rev.5 为“百业户籍”

此前版本虽已覆盖人物、关系、国势、城池与施政，但仍明显“**政务过重、百姓过轻**”。v2.1 以联合国 **ISIC Rev.5** 与马来西亚统计局 **MSIC 2025** 作产业本体，不再自造“百业”分类。

- 联合国统计委员会于 2023 年通过 **ISIC Rev.5**，用于把全球经济活动放进一致的产业分类框架。
- 马来西亚统计局现行 **MSIC 2025** 与国际框架衔接，A–V 共 **22 个 Section、88 个 Division、260 个 Group、467 个 Class、1,248 个 Item**；2025 版还显式吸收数据中心、无人机、内容创作者、影响者、电子竞技、数码资产交易等新产业。
- 因而“治国策略”不再只看 P 类（公共行政与国防），而必须同时观察 A–V 全部产业、劳动者、个体经营者、家庭、消费者、专业人士、研究人员、创作者、社会组织与地方社区。

### 地缘数据的“五坐标铁律”

任何跨地球／太空记录，除 `source_id + as_of` 外，再强制五坐标：

1. **空间坐标**：地球用经纬度／行政区／EPSG；太空用参考系、中心天体、轨道／状态向量。
2. **时间坐标**：UTC 与任务需要的天文时标分清；不得把不同 epoch 的轨道／经济数据硬拼。
3. **法律坐标**：国家法、国际法、条约义务、商业合同、非约束性原则分栏。
4. **成熟度坐标**：`operational / under_development / announced / conceptual / retired`。
5. **证据坐标**：`observed / administrative / estimated / modeled / forecast / claimed_by_actor`。

> **太阳系不是“把世界地图放大”**：地球国家数据可按领土与行政统计；轨道对象按注册、运营、轨道与任务；月球／火星等天体必须另设 `legal_regime`，不得默认主权归属。

## 断语、盲区与诛心

无一家把「人物数值 ＋ 势力经营 ＋ 外交征战」做成一站式。此与两附件结论一致，本次复核未推翻。三重缺口恒在：

1. **口径**：现实无可靠之单一「武力 87」。LTA 所出乃带抽样误差之文本特质估计。
2. **准入**：第六至九门九成只售政府、军方、法人，不面向个人。
3. **法禁**：对在世私人作人格画像，多数法域受限；Cambridge Analytica 为前车。公众人物之公开言论，法律空间宽得多。

### 诛心：此问之前提须先斩

游戏能给人物打 87、给国力画面板，因其具三性：规则闭合、参数可观测、开局可重复。现实三者皆无——规则随时改写，变量多不可测，历史只跑一次、无对照组。

故凡自称能售「治国最优策」者必诈。现实市场真正售的只有两样：**证据供应**（谁与谁有关、何处正在发生何事，第一、三、四、五门售此）与**情景穷举**（若干假设下会如何、哪条假设最脆，第六、八门售此）。第三样「结论」，无人能售，亦不该买。

更须诛者：**看起来像游戏，遂误以为已量化了现实**。a168 之 #075 即前例——`q` 侧与 `e` 侧两管线同窗同锚，仅差 `bet05 > 0` 与 `bet08 IS NOT NULL` 两条谓词，便令 CSV 之 `n_rounds` 与门槛所卡者非同一量。人物面板风险全同：面板上五个数，可能各出自五条不同管线。

## killcritic／一票否决

任一条触犯，人物／治国模块即不得进入正式决策：

1. **无来源、无时点、无版本**仍给人物或国家打分。
2. 由族群、姓氏、血缘、宗教、地域等身份推断人的忠诚、能力、犯罪风险或适任性。
3. 把关系网络中心性、共同任职、合照或同校直接解释成同盟、利益输送、敌意或共谋。
4. 把 LTA／LLM 文本特征写成人格诊断、精神状态、智力或「治国能力」的独立结论。
5. 把 IFs／AnyLogic／兵棋的情景输出写成未来发生概率；把预测概率写成因果效果。
6. 用预测市场价格或群智聚合结果替代事实核验，或让系统据此替用户作政治选择。
7. 对在世者或公众参与者收集／推断个人资料而无合法目的、目的限制、访问控制与必要的 DPIA／人工复核。
8. 高影响人事、财政、土地、公共服务或纪律处分由黑箱模型自动决定而无责任人、理由码、申诉与回滚。
9. 生产环境允许检索网页／外部文档中的提示直接调用高权限工具。
10. UNKNOWN 被偷偷填成 0、平均值或大模型猜测。

### v2.2 critic／范围扩张的七个反问

1. **太阳系很大，但有效样本很小**：地球之外多数经济活动仍是科研／工程任务与规划，不能制造“月球 GDP”“火星就业率”式伪统计。
2. **宇航计划高度版本化**：任务日期、架构、合作伙伴、预算会改变；每条项目必须带 `as_of` 和状态。
3. **空间地缘不能变成地缘决定论**：轨道位置、资源禀赋和距离是约束，不自动决定政治或商业结果。
4. **“全地球数据”也不等于全体人类**：数字鸿沟、非正规经济、战乱地区、偏远社区仍可能缺数。
5. **地球民生必须压过太空虚荣指标**：宇航投资评价同时看科研、产业、教育、基础设施外溢和机会成本。
6. **军事数据最容易被误用**：本录只留宏观投入、产业、事件与韧性；不把开放数据加工成行动目标。
7. **AI 地缘不能只数 GPU**：算力受芯片、能源、水、网络、土地、人才、融资与监管共同制约。

### v2.2 killcritic／寰宇一票否决

出现任一项即冻结该结论／模型，不得进正式决策层：

1. 无 `source_id + as_of + scale`；
2. 太空对象无 `frame/epoch/unit`；

11. 多数据源单位、口径或地理层级无法对齐；

## blueprint／蓝图：四层主干不拆，增「三横梁＋九家分职」

原稿四层仍是主干；本版**不另起炉灶**，只加三条横梁，使之从「可分析」升为「可审计、可治理、可降级」。

### 三横梁

1. **史源横梁（Provenance）**：每个事实／分数／情景均绑定 `source_id → snapshot → parser/model_version → run_id → output_hash`。
2. **法度横梁（Governance）**：最小权限、职责分离、DPIA、理由码、人工责任人、申诉、回滚、保留期。
3. **攻守横梁（Security & Resilience）**：零信任、数据分区、密钥分离、SBOM／SLSA、制品签名、提示注入测试、离线沙盒、优雅降级。

## v2.1 高见：从「治国软件名录」升级为「天下人物—百业—家庭—组织—资源—政策—结果」决策母体

更强的方案不是再加一百个品牌，而是让任何新平台都只能挂到同一套标准本体与证据闸门上：

1. **政不独尊，民生为底**：P 类公共行政只占 MSIC 22 个 Section 之一；每项政策必须同步看居民／家庭、劳动者、小微商户、企业／投资者与公共服务方。
2. **人不一分，因事立证**：一人可以同时是居民、雇员、股东、家长、志愿者、创作者；系统按“角色 × 任务 × 时点”建证据，不造永久人格总分。
3. **业不孤立，链上看势**：行业不是孤岛；用 `supplier → establishment → worker → household → consumer → tax/service → outcome` 串起产业链与民生链。
4. **先官方底册，再商业增量**：马来西亚先以 DOSM／MSIC、SSM、官方劳统／家庭调查为基线；Lightcast、Capital IQ、NIQ、CoStar 等只补市场粒度，不反客为主。
5. **普通百姓默认聚合优先**：政策研究先问“哪个群体、哪个地区、哪类职业”，而不是“这个私人个体忠不忠诚”。私人个体层只有在授权、明确目的、必要性与可申诉条件下才下钻。
6. **军工只借工程，不借战争逻辑**：吸收可审计、双人复核、分级隔离、故障安全、红队、恢复演练；不把军事敌我模型套在普通居民、异议者、消费者或竞争企业身上。
7. **采购看增量效度，不看品牌神话**：任何商业平台必须与 R／Python／官方免费数据基线做 A/B 式 PoC；若没有可量化增量，NO-BUY 即为成功裁定。

> **最终母句**：先正名，后计数；先百业，后总分；先家庭与民生，后宏观叙事；先证据，后人物；先情景，后抉择；先责任，后自动化。


## v2.2 高见：从「天下百业」再升为「地球—轨道—太阳系社会技术系统」

本版最重要的不是再添二十五个资料源，而是改写“地缘”的基本单位：

1. **地缘不只看国界，要看网络**：港口、航路、电网、海缆、数据中心、矿产加工、芯片厂、科研网络、轨道壳层与地月通信都可能比行政边界更直接地决定约束。
2. **地缘不只看强者，要看家庭与生态**：任何宏观情景都必须回算到家庭、劳动者、小微企业、公共服务、水粮健康与生态外部性。
3. **地缘军事不等于战争教程**：研究军费、军工企业、矿物、供应链和冲突暴露，是为了理解成本、韧性与民生外溢；系统明确禁止输出攻击目标与行动优化。
4. **AI 是基础设施问题，不只是模型问题**：芯片→电力→水→网络→数据中心→人才→模型→应用构成地缘 AI 链；任何“AI 强国指数”若不含这些约束，只是表面分数。
5. **宇航是产业链＋标准＋科学＋法律的组合**：发射只是入口；真正长期价值还包括地面站、通信导航、空间天气、轨道可持续、科学档案、人才、保险、责任和行星保护。
6. **太阳系研究先做“星历／任务／标准／状态图”，后做经济叙事**：没有可靠资产与交易统计时，不虚构月球 GDP、火星市场份额或资源储量。
7. **古典思想只负责“问什么”，现代科学负责“如何证”**：史家钉源、名家正名、墨家验伪、农商算账、纵横列势、兵家压力试、道家知止；但轨道位置交给 Horizons／SPICE，气候交给 WMO／ECMWF，健康交给 WHO，贸易交给 UN/WTO，法源交给 UNOOSA。
8. **最后不是“太阳系国力排行榜”，而是多目标韧性图谱**：输出 `能力—依赖—成本—外部性—不确定性—法律—成熟度—撤回条件`，让决策者看到哪里可靠、哪里只是愿景。

> **v2.2 最终母句**：先正名，后计数；先尺度，后比较；先地球民生，后太空愿景；先轨道与法度，后资源叙事；先证据，后情景；先责任，后自动化。


## 附录 A · 保密、攻防与高可靠工程基线

本节借鉴安全关键系统、国防／宇航的软件保证思想，但**只移植治理与可靠性工程，不提供现实作战、攻击或规避执法方法**。

| 域 | 最低基线 |
| --- | --- |
| 身份 | 零信任；人／服务账户分离；MFA；短时凭证；最小权限 |
| 数据 | Public／Internal／Confidential／Restricted 四级；人物个人资料与公众参与资料独立域 |
| 网络 | 默认拒绝；敏感研究环境无互联网出站；连接器白名单；高风险工具单独审批 |
| 模型 | 模型卡＋数据表＋训练／评测截止日；离线对照；影子运行；漂移／校准监控 |
| RAG／Agent | 检索内容无指令权；外部文本提示注入检测；工具参数 schema；高影响工具需人工确认 |
| 软件供应链 | `renv.lock`／Python lock → CycloneDX／SPDX SBOM；SLSA；签名；CVE 扫描 |
| 日志 | append-only／WORM；决策输入、模型版本、人工修改、输出与回滚全留痕 |
| 冗余 | 关键指标双实现／三读法；不一致即冻结，不自动择一 |
| 降级 | 模型不可用→规则；规则不可用→人工；证据不足→UNKNOWN |
| 演练 | 每季做恢复／回滚／权限泄漏／供应链污染／提示注入桌面演练 |

## 附录 B · 一句话军令
