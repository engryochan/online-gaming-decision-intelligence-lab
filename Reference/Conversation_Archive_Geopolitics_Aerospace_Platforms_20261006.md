## 一、原始查詢與首次回復摘要

**用戶查詢**（中文）:  
請問先生可否先查證那些世界最前沿兼頂尖高端的地緣學、軍事、宇航、策略服務平臺是使用哪些軟件、組件、平臺、設備等等呢？請一一列出。

**首次回復結構**（已存檔於 previous_response_geopolitics_platforms_20261006.md）:
- 地緣政治與策略分析：Palantir Gotham/Foundry/AIP、Janes、Crucible、Govini、OSINT 工具集
- 軍事 C4ISR：Lockheed C2BMC、Northrop/RTX/BAE/L3Harris、SOCET GXP、Esri ArcGIS、ATAK
- 宇航/SSA：Ansys STK+ODTK、COMSPOC、GMV Ecosstm、LeoLabs/Slingshot 等
- 通用底層：數據融合、GIS、仿真、雲與安全、開源 OSINT
- 硬體：傳感器、邊緣計算、顯示終端
- 重要說明：密級限制、趨勢為軟件定義/AI 驅動/多域融合、互操作性

## 二、附件《地緣學、軍事、宇航、策略服務平臺提問.txt》審閱與核實

該附件彙編多模型（Claude、ChatGPT、Meta AI、Copilot 等）對同一問題的回答。依 Geostrategy 報告證據規則（VERIFIED / UNKNOWN / 不得臆測）逐項裁定：

| 問題點 | 裁定 |
|--------|------|
| Athea 寫成 Helsing×Saab | **更正為 Thales × Eviden**（athea.tech 官方） |
| Ansys 歸屬 | **2025-07-17 Synopsys 完成收購**；STK 仍為產品品牌 |
| i2 Analyst's Notebook | **2022 由 Harris Computer 自 IBM 收購**，現為 i2 Group |
| 「起源國即全面禁用」ITAR/EAR/CMMC | **撤回概括**；改為物項/交易/合同逐案判定 |
| StarRocks「秒級上限／百萬點必崩」、ECharts「上萬通道必卡」 | **撤回未測試數值**；改為設計目標差異 + 須實測 |
| NASA VEDA 用 Airflow | 倉庫存在可支持；**不能證成「航空航天通用標配」** |
| SitaWare「北約標準」、跨國採用數 | 產品頁支持 C4ISR 用途；正式標準身份與各項 2026 里程碑未本輪核實 |
| UDL 數量級、SpaceX 完整栈、Sift 為 SpaceX 自研、國家單一技術栈 | **保持 UNKNOWN 或撤回** |
| 攻防/加解密/密級配置細節 | 不得臆測；僅列公開架構層（Zero Trust、mTLS、HSM 等公開標準） |

多模型回答中有價值且經核實的公開層內容已吸收進兩份報告的「經核實軟件/組件清單」與 Aerospace 校訂表。

## 五、方法紀律（全程遵守）

1. 密級架構、具體任務配置、武器內部參數 → UNKNOWN  
2. 技術判定與合規判定分寫  
3. 未測試性能數字不得作為結論  
4. 供應商合同名單 ≠ 開源依賴清單  
5. 不用「高級／低級」比較，改用硬實時、確定性、時空分區、TCB、WCET、認證等級
