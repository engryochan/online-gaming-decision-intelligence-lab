二、Redteam：先修正最容易誤判的五個概念
================================================================

R1｜「讀心」不是一個單一技術名詞
應拆成：
- 腦狀態分類（attention/fatigue/arousal）
- 運動意圖解碼（motor intention）
- 嘗試說話解碼（attempted speech）
- 內在語言解碼（inner speech）
- 視覺／感覺表徵解碼
- 腦刺激／感覺寫入
- 腦—腦資訊傳輸（brain-to-brain interface, BBI）
- 完整思想／記憶／意識互傳

上述能力的科學難度相差數個量級，不得全部叫「讀心」。

R2｜「遠程」至少有三種完全不同的意義
- D0：感測器仍貼身／植入，只是資料在本機處理；
- D1：感測端貼身／植入，但資料經無線／互聯網傳到遠端設備；
- D2：兩端各自有腦機介面，解碼後的有限資訊經網路傳輸；
- D3：不需要任何貼身／近距感測器，從遠距直接取得語義思想；
- D4：任意距離完整思想／記憶／意識直接互傳。

截至核驗時點，有公開人體證據的是 D0–D2 的部分形態；
沒有可信公開證據證明 D3–D4 已能對自由思想做可靠、通用、秘密式讀取。

R3｜「網路很遠」不等於「感測很遠」
BrainNet 可把已取得的腦訊號經 Internet 傳輸；
這證明的是「網路遠程傳輸」，不是「在數百公里外隔空讀取大腦」。

R4｜「跨城腦控」不等於「腦—腦」
例如兩名受試者各自用 BCI 控制棋局，棋步經普通網路傳到另一端，
這是「腦→設備→網路→設備」；若沒有把一人的腦訊息直接轉為另一人大腦的刺激輸入，
不得升級為 N5 腦—腦介面。

R5｜「FDA 510(k) cleared」不等於「整套 BCI 已上市」
Precision Neuroscience 的 Layer 7-T 取得 510(k) 的對象是皮層電極（cortical electrode）；
其完整無線 BCI 系統仍在研發／研究使用。未來母表必須把 component_regulatory_status
與 system_regulatory_status 分欄。

三、Critic：把七階從「單軸」升級為「六軸」
================================================================

原 N0–N7 保留，因其作為「能力階級」非常有用；但不再拿 N 階同時代表：
證據、臨床成熟度、侵入性、遠程程度或語義自由度。

A. 能力階級 capability_level（保留原七階）

| 階 | 我方名 | 嚴格定義 | 2026-10-07 公開證據判定 |
|---|---|---|---|
| N0 | 察神 | 腦／神經生理狀態感測與特徵分類 | 已成熟；EEG/fNIRS/MEG 等多路線 |
| N1 | 辨意 | 注意、選擇、運動想像、有限意圖分類 | 已有人體實用/研究 |
| N2 | 馭器 | 神經意圖控制電腦、遊標、輪椅、機械臂、智慧家居 | 人體臨床前沿已成立 |
| N3 | 譯言 | 神經活動→文字／合成語音／數字化身表達 | 人體前沿已成立 |
| N4 | 讀默 | 直接解碼內在語言／默念，且非單純運動輸入代理 | 已有受限人體實驗；自由內語尚未成立 |
| N5 | 通神 | 一人大腦輸出→網路／中介→另一人大腦輸入的有限資訊 | 已有人體低頻寬驗證 |
| N6 | 神交 | 自然語言級、自由語義、雙向、高頻寬腦—腦通信 | 尚無可信公開實現 |
| N7 | 心印 | 任意距離完整思想、記憶、感覺、情緒、意識互傳 | 無可信公開證據 |

B. 證據級 evidence_grade（新增）
- E0：REGULATORY/STANDARD——監管資料庫、正式標準、臨床註冊等。
- E1：PEER_REVIEWED_HUMAN——同行評審人體研究。
- E2：INSTITUTIONAL_FIRST_PARTY_HUMAN——大學/醫院/公司官方人體結果，但主要數據尚未獨立重複。
- E3：PRECLINICAL/PROTOTYPE——動物、離體、工程原型。
- E4：RESEARCH_TARGET/VENDOR_CLAIM——研發目標、路線圖、行銷宣稱。
- E5：UNKNOWN/CONTRADICTED——查無可靠證據或與可靠資料衝突。

C. 侵入性 invasiveness
- I0：非侵入（EEG、fNIRS、MEG、fMRI 等）
- I1：血管內／低侵入
- I2：皮層表面／硬膜下／ECoG 類
- I3：皮層內微電極／intracortical

D. 語義開放度 semantic_openness
- S0：二元／少數固定選項
- S1：封閉詞彙／固定模板
- S2：連續控制／開放設備操作，但不等於語言
- S3：開放式嘗試說話／文字
- S4：受限內在語言
- S5：自由、非合作、非任務限制的完整思想內容（未證實）

E. 距離方式 distance_mode
- D0：本地貼身／植入
- D1：本地採集 + 無線到附近設備
- D2：本地採集 + Internet/廣域網傳輸
- D3：遠距非接觸語義腦讀取（未證實）
- D4：任意距離完整腦—腦／意識互傳（未證實）

F. 成熟度 maturity_status
- LAB
- HUMAN_RESEARCH
- EARLY_FEASIBILITY
- REGULATORY_COMPONENT
- CLINICAL_INVESTIGATIONAL
- COMMERCIAL_NONMEDICAL
- COMMERCIAL_MEDICAL
- RESEARCH_TARGET

【硬規則】
N_level 永遠回答「能做什麼」；
E_grade 回答「證據有多強」；
maturity 回答「做到哪一階段」。
三者不得互相替代。

================================================================
四、Killcritic：截至 2026-10-07 的「阿凡達基準」
================================================================

把《阿凡達》式神經連接拆成七個必要條件：
1. 高頻寬感覺輸入；
2. 高頻寬運動輸出；
3. 自由語義；
4. 情緒／感受；
5. 全身控制；
6. 雙向閉環；
7. 近乎即時且自然的長時間穩定使用。

現實已分別出現：
- 運動意圖→電腦／機械臂：有；
- 嘗試說話→文字／聲音：有；
- 內在語言→有限文字：有實驗；
- 腦→數字化身：有；
- 腦→Internet→腦：有低頻寬驗證；
- 腦→機器人／外骨骼：有；
- 感覺回饋／神經刺激閉環：有多條研發與部分人體路線。

但「全部條件合一」的 N6/N7 系統截至本核驗日仍無可信公開證據。
因此「比《阿凡達》更高端的完整遠程心靈相通」不能標 VERIFIED。

1. 美國 USA

[USA-01] Neuralink
- 類型：公司 / 植入式 BCI
- 能力：N2 已有人體；N3 語言方向已進入 VOICE 臨床研究路線
- 侵入性：I3
- 證據：E0/E2
- 核驗重點：
  * 2026-01-28 官方稱全球試驗已有 21 名 Neuralnauts。
  * Telepathy 主要解碼運動相關神經活動，控制電腦、手機、機械臂，不是「完整讀心」。
  * VOICE 研究目標是將與語言產生有關的皮層訊號轉為文字／語音。
  * 2026-10-01 官方另公布 50,000 小時無標註腦資料預訓練與 11.32 BPS 的第一方性能紀錄；
    應標 FIRST_PARTY_RESULT，不等於獨立複現。
- 判定：N2 VERIFIED；N3 CLINICAL_INVESTIGATIONAL；N7 CONTRADICTED_BY_SCOPE。

[USA-02] Paradromics / Connexus BCI
- 類型：公司 / 全植入皮層內 BCI
- 能力：N3
- 侵入性：I3
- 證據：E0（FDA IDE）+ E2（公司人體結果）
- 核驗重點：
  * 2025-11 FDA IDE 允許 Connect-One Early Feasibility Study。
  * 2026-06 首名長期 Connexus 人體植入。
  * 2026-09 公司公布首名參與者以神經活動進行即時文字／合成語音，並回答開放式問題。
- 判定：N3 HUMAN/CLINICAL；具很高優先級，但性能細節宜等待同行評審與多受試者重複。

[USA-03] Precision Neuroscience / Layer 7
- 類型：公司 / 高密度皮層表面介面
- 能力：N2 為主；高密度神經解碼平台
- 侵入性：I2
- 證據：E0/E2
- 核驗重點：
  * FDA K242618：Layer 7-T 為「cortical electrode」，2025-03-30 510(k) 判定 substantially equivalent。
  * 公司稱 Layer 7 cortical interface 已有 100+ implanted clinical study patients、18+ hospital partners，
    並示範電腦與機器人控制。
  * 必須分清：獲 510(k) 的電極組件 ≠ 完整無線 BCI 系統已核准上市。
- 判定：COMPONENT_REGULATORY VERIFIED；完整 BCI 仍 INVESTIGATIONAL。

[USA-04] Synchron / Stentrode
- 類型：公司 / 血管內 BCI
- 能力：N2
- 侵入性：I1
- 證據：E1/E2
- 核驗重點：
  * Stentrode 位於腦血管內，讀取運動意圖；
  * 已用於文字、瀏覽、購物與數位設備控制；
  * Synchron 明確標示 investigational device；
  * 其研究頁列有 2023 JAMA Neurology、2025 Journal of Neural Engineering 等人體/臨床相關成果。
- 判定：N2 HUMAN VERIFIED；不是 N4/N5。

[USA-05] Meta AI / Brain2Qwerty v2
- 類型：公司科研 / 非侵入式 MEG + AI
- 能力：神經活動→文字，屬 N3 類研究能力；不應誤判 N4
- 侵入性：I0
- 證據：E2（官方研究頁；論文為 arXiv）
- 核驗重點：
  * 約 22,000 句、9 名受試者、每人約 10 小時 MEG；
  * 平均 word error rate 約 39%，即平均 word accuracy 約 61%；最佳受試者約 78% word accuracy。
  * 關鍵限制：受試者是在「主動打字」任務中採集 MEG，並非任意內心思想的被動讀取。
- 判定：N3 R&D；NOT N4 FREE INNER SPEECH。

[USA-06] UCSF / NIH 資助多模態神經義體
- 類型：大學/醫院科研
- 能力：N3 + AVATAR
- 證據：E1
- 核驗重點：
  * 2026 Nature Neuroscience / NIH 報告 3 名癱瘓患者；
  * 即時解碼同時語音與上半身姿勢，驅動個人化數字化身。
- 判定：N3 VERIFIED；「類 Avatar」只在「神經意圖驅動數字身體」這一狹義層面成立。

[USA-07] Stanford 內在語言研究
- 類型：大學科研
- 能力：N4（受限）
- 侵入性：I3
- 證據：E1/E2
- 核驗重點：
  * 4 名嚴重運動/語言障礙受試者；
  * 研究證明內在語言在相關運動皮層有可解碼表徵；
  * 研究者同時明確表示：現有 BCI 尚無足夠解析度/可靠性準確解碼「不受限制的自由內在語言」。
- 判定：N4 LIMITED VERIFIED；S4，不是 S5。

[USA-08] University of Washington / BrainNet
- 類型：大學科研 / BBI
- 能力：N5
- 侵入性：I0（EEG + TMS）
- 距離：D2
- 證據：E1
- 核驗重點：

  * 五組三人組（共 15 人），平均任務正確率約 81.25%；
  * 資訊主要是有限二元決策；
  * 發送端 EEG，接收端 TMS 刺激視覺皮層。
- 判定：N5 VERIFIED-LOW-BANDWIDTH；S0，不得寫成完整思想互傳。

[USA-09] DARPA N3（Next-Generation Nonsurgical Neurotechnology）
- 類型：政府科研計畫
- 能力：雙向非手術腦機介面研發
- 證據：E0/E3
- 核驗重點：

九、Cheatsheet：三十秒判讀一項「讀心科技」
================================================================

問 1：感測器在哪？
- 頭皮、頭盔、MRI/MEG、血管、皮層表面、皮層內？
若完全沒有任何近距感測或植入，卻聲稱能遠距精準讀自由思想，證據門檻必須極高。

問 2：使用者是否主動配合？
- 注視刺激、想像手動、嘗試說話、默念密碼、主動打字？
若答案是「是」，不得包裝成被動偷讀全部思想。

問 3：輸出是什麼？
- 專注分數？
- 左/右？
- 遊標？
- 固定詞彙？
- 開放句子？
- 內在語言？
不同輸出對應完全不同 N 階。

問 4：是否真的「寫入另一個大腦」？
若只是把腦控命令透過 Internet 傳到另一臺電腦，仍不是 N5。

問 5：證據從哪裡來？
優先 E0/E1；企業宣稱要標 E2/E4；沒有獨立複現不可寫成世界定論。

問 6：監管批的是「組件」還是「整套系統」？
這一條直接防止 Precision 類誤讀。

十一、Redteam + Critic + Killcritic + Blindspot 七件套總結
================================================================

Redteam/
- 專抓「遠程、讀心、全腦、意識、軍用、超越 Avatar」等高風險強斷言；
- 沒有 E0/E1/E2 可靠鏈不得升級。

Critic/
- 將 N_level 與 evidence/maturity 拆開；
- 將「網路遠程」與「感測遠程」拆開。

Killcritic/
- 任意一項若只做到狀態分類、固定詞彙、運動想像，立即阻止升 N4；
- 沒有 receiver-brain stimulation/input chain，立即阻止升 N5；
- 沒有自由語義 + 雙向 + 高頻寬 + 人體重複，立即阻止升 N6；
- 沒有完整意識/記憶/情緒/感覺可驗證互傳，立即阻止升 N7。

Blindspot/
- 注意 component approval ≠ system approval；
- first-party demo ≠ independent replication；
- patent ≠ prototype ≠ human trial ≠ product；
- military interest ≠ secret deployed capability；
- cross-city device control ≠ brain-to-brain。

Blueprint/
- ISO master + entity child table + evidence claim table + regulatory table + paper table；
- 支持跨國多對多法域，不把跨國企業硬塞成單一國家成果。

Cheatsheet/
- 感測器在哪？
- 人是否配合？
- 輸出開放度？
- 是否真的寫入另一腦？
- 證據級？
- 組件還是整系統？

Actionplan/
- 249 ISO 地毯查證；
- N4–N6 重大突破監測；
- 舊內容留痕；
- UNKNOWN 不猜；
- 博彩資料隔離；
- 禁止退化，惟許增強。

## 十三、249 ISO 母表的处理军令

接下来不是给 249 行胡乱填名字。

**249 ISO 条目**
